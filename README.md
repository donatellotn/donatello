# Donatello — Salon de Thé

A premium digital experience for **Donatello** — a retro-vintage salon de thé in Bizerte, Tunisia.

## About the Project
Donatello is a visually striking café that masterfully blends a nostalgic, retro aesthetic with a fresh, modern atmosphere. This website serves as a digital showcase for the café's unique ambiance, menu, and contact information.

## Features
- **Smooth UI** — Fluid animations and seamless transitions powered by Framer Motion
- **Responsive Design** — Optimized for all screen sizes, from mobile to desktop
- **Fast Performance** — Built with Vite for instant load times
- **Dynamic Menu** — Live menu managed through menu-data.html
- **SEO Ready** — Structured data, Open Graph tags, and semantic HTML
